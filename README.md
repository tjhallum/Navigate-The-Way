# Navigate The Way ✝️ System Prompt

This public repository contains the open and inspectable **Navigate The Way ✝️ (NTW✝️) system prompt** and related prompt modifiers.

NTW✝️ publishes these materials so users, pastors, church leaders, and developers can examine the theological commitments and response standards shaping its AI output.

## Current prompt components

- [`ntw_system_prompt_apologist/ntw_system_prompt_apologist.txt`](ntw_system_prompt_apologist/ntw_system_prompt_apologist.txt) — core NTW✝️ prompt used by the Apologist AI-hosted experience.
- [`ntw_system_prompt_apologist/ntw_system_prompt_apologist_scripture.txt`](ntw_system_prompt_apologist/ntw_system_prompt_apologist_scripture.txt) — Scripture-handling policy used with the Apologist AI-hosted experience.
- [`modifiers/`](modifiers/) — conversational and age-oriented prompt modifiers.

[`ntw_system_prompt_chatgpt.txt`](ntw_system_prompt_chatgpt.txt) is retained as a historical prompt artifact from the retired ChatGPT-hosted version. It is not the current NTW✝️ prompt.

## Repository scope

This repository intentionally contains **prompt and transparency materials only**.
